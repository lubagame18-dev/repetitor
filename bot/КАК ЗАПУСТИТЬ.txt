БОТ «Уроки русского языка. Подготовка к ОГЭ» – как запустить

1. Создать бота (5 минут)
   - В Telegram откройте @BotFather → /newbot.
   - Имя: Уроки русского языка. Подготовка к ОГЭ
   - Адрес (должен заканчиваться на bot), например: uroki_russkogo_oge_bot
   - BotFather пришлёт токен – длинную строку вида 123456:ABC... Никому её не показывайте.
   - Там же: /setuserpic – загрузите котика (файл kotik.png из архива).

2. Запустить бота
   Бот работает, пока запущена программа. Варианты:
   а) На своём компьютере (для проверки):
      pip install "python-telegram-bot[job-queue]==21.6"
      Windows (PowerShell):
        $env:BOT_TOKEN="ваш_токен"; $env:APP_URL="ссылка_на_приложение"; python bot.py
   б) Чтобы работал всегда – бесплатный или недорогой хостинг для Python
      (например, PythonAnywhere, Amvera, Timeweb Cloud): загрузить папку целиком,
      указать переменные BOT_TOKEN и APP_URL, команда запуска: python bot.py

3. Настройки (переменные)
   BOT_TOKEN   – токен от BotFather (обязательно)
   APP_URL     – ссылка на приложение с папками
   TUTOR_ID    – ваш id в Telegram (напишите боту /id), чтобы делать рассылки командой /say
   LESSON_HOUR, LESSON_MIN – время начала занятия (по умолчанию 17:00, Екатеринбург)
   LESSON_LEN  – длительность занятия в минутах (по умолчанию 60)

4. Подключить ученика
   Ученик открывает бота по ссылке t.me/имя_бота и нажимает «Старт».
   Имя бота впишите в приложении: вкладка «План» → «Настройки» – на главной
   появится кнопка «Бот в Telegram».

Что бот делает сам
   - в среду в 19:00: «Завтра занятие» + тема + какое ДЗ сдать;
   - в четверг за 3 часа до занятия: напоминание;
   - после занятия: «Пройди тест в папке» + новое домашнее задание;
   - накануне итогового собеседования (9 февраля): напоминание.
Команды: /next, /dz, /plan, /app, /say текст (рассылка от репетитора).

Расписание бот берёт из plan.json – того же плана, что в приложении.
