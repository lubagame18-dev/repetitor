# Платформа «Учу по ФРП · репетиторство» – как опубликовать

В архиве три части:

| Папка | Что это |
|---|---|
| `repetitor/` | сайт: приложение ученика (`index.html`) и кабинет учителя (`teacher.html`). Её публикуем на GitHub. |
| `repetitor/supabase/schema.sql` | база данных: ученики, тесты, домашки. Выполняется один раз в Supabase. |
| `bot/` | Telegram-бот с напоминаниями (по желанию, запускается отдельно). |

Сайт работает и без базы: ученик входит по имени, результаты хранятся только на его телефоне. Чтобы результаты приходили вам в кабинет, нужен шаг 1.

---

## Шаг 1. База Supabase (15 минут)

Лучше завести **отдельный проект**, чтобы не смешивать с базой «Учу по ФРП» (на бесплатном тарифе можно два проекта).

1. supabase.com → **New project**. Имя: `repetitor`, регион – ближайший (Frankfurt). Пароль базы сохраните.
2. Слева **SQL Editor** → **New query** → откройте файл `repetitor/supabase/schema.sql`, скопируйте всё → вставьте → **Run**. Должно появиться «Success».
3. Слева **Authentication** → **Users** → **Add user** → **Create new user**: ваша почта и пароль, галочка **Auto Confirm User** → Create. Это вход в кабинет учителя.
4. **Authentication** → **Sign In / Providers** (или Settings) → выключите **Allow new users to sign up** → Save. Так чужие люди не смогут создать кабинет.
5. **Project Settings** → **API** (Data API / API Keys) → скопируйте:
   - **Project URL** (вида `https://abcd.supabase.co`);
   - ключ **anon public** (длинная строка). Ключ `service_role` никуда не вставлять!
6. Откройте файл `repetitor/config.js` в Блокноте и вставьте их вместо `ВАШ-ПРОЕКТ` и `ВАШ-ANON-KEY`. Сохраните.

## Шаг 2. Публикация на GitHub

### Вариант А (рекомендую): папка на вашем сайте
Тогда адреса будут `uchu-po-frp.ru/repetitor/` и `uchu-po-frp.ru/repetitor/teacher.html`.

1. Откройте репозиторий `lubagame18-dev/uchu-po-frp` на github.com.
2. **Add file** → **Upload files**.
3. Перетащите в окно **саму папку `repetitor`** целиком (из проводника, не её содержимое) – GitHub сохранит подпапки.
4. Внизу **Commit changes**.
5. Через 1–2 минуты откройте `https://uchu-po-frp.ru/repetitor/`.

### Вариант Б: отдельный репозиторий
1. github.com → **New repository** → имя `repetitor` → Public → Create.
2. **uploading an existing file** → перетащите **содержимое** папки `repetitor` (файлы `index.html`, `teacher.html`, `config.js` и папки `assets`, `courses`, `icons`, `supabase`) → Commit.
3. **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://lubagame18-dev.github.io/repetitor/`.

## Шаг 2½. Общая доска (Realtime)
Доска с курсорами работает через Supabase Realtime – он включён в новых проектах сам. Если курсор ученика не появляется у вас на доске: Supabase → **Realtime** → **Settings** → убедитесь, что разрешены публичные каналы (**Allow public access** включено).

## Шаг 3. Кабинет учителя и первый ученик

1. Откройте `…/repetitor/teacher.html` → войдите почтой и паролем из шага 1.3.
2. **Добавить ученика**: имя, курс «Подготовка к ОГЭ. Русский язык» → кабинет выдаст **код** и **ссылку**.
3. Нажмите **Копировать** и отправьте ссылку ученику. По ссылке он сразу входит под своим именем.
4. В кабинете видно по каждому ученику:
   - средний процент и карта успеха по блокам ОГЭ;
   - каждый тест: последняя и лучшая попытка, число попыток, рекомендация;
   - правила, в которых чаще всего ошибки;
   - домашние задания: отметка ученика, его ссылка или комментарий, кнопки **Принять** / **На доработку**, оценка и комментарий (ученик видит их у себя).
5. Вкладка **Курс**: теория, практика **с ключами**, тест с ответами по каждому занятию. В разделе «Рабочий лист и ДЗ» можно вставить ссылку на рабочий лист из «Учу по ФРП» – она появится у всех ваших учеников этого курса.

## Шаг 4. Ученик ставит приложение на iPhone

1. Открыть ссылку в **Safari** (не в Telegram и не в Chrome).
2. **Поделиться** (квадрат со стрелкой) → **На экран «Домой»** → **Добавить**.
3. На экране появится иконка с котиком. Приложение открывается на весь экран и помнит вход.

Android: Chrome → меню ⋮ → **Добавить на главный экран**.

## Шаг 5. Telegram-бот (по желанию)
Инструкция – в `bot/КАК ЗАПУСТИТЬ.txt`. В переменную `APP_URL` впишите адрес сайта из шага 2. Имя бота впишите в `config.js` → `BOT_USERNAME`, тогда на главной у ученика появится кнопка.

## Что есть в каждой папке занятия
- **Теория** со схемами и «Как запомнить».
- **Практика** – задания на занятие (ключи только у учителя).
- **Доска** – общая с учителем: курсоры обоих, ручка, маркер, текст, ластик; листы «Практика», «Теория», «Текст для письма», «Чистый лист». Всё сохраняется.
- **Письмо** – шаг письменной линии, текст, тема, редактор со счётчиком слов. Работа уходит учителю, оценка по критериям возвращается ученику.
- **Домашка** – задание, ДЗ-тест (5 вопросов, результат сразу в карту успеха), отметка «Я сделал ДЗ».
- **Тест** – тест по занятию.

В кабинете учителя у каждого занятия есть вкладка **Методика** (план по минутам и советы), а в меню – **Методика курса**.

## Как обновлять

- После обновления платформы снова выполните `supabase/schema.sql` в SQL Editor: файл можно запускать повторно, данные не удаляются.
- Изменили файлы → загрузите их в ту же папку на GitHub (Upload files заменит старые).
- Чтобы у учеников точно обновилось: в `index.html` и `teacher.html` поменяйте `?v=1` на `?v=2`, а в `sw.js` – `oge-rus-v1` на `oge-rus-v2`.

## Как добавить другой курс (другие ученики)

1. Скопируйте `courses/oge-rus.js` → например `courses/ege-rus.js`, внутри замените `"oge-rus"` на `"ege-rus"`, поменяйте даты, темы, материалы.
2. Ключи – так же: `courses/ege-rus-keys.js`.
3. В `index.html` и `teacher.html` добавьте строку рядом с подключением `oge-rus.js`:
   `<script src="courses/ege-rus.js?v=1"></script>` (в кабинете – и файл ключей).
4. В кабинете при добавлении ученика выберите новый курс.

Если у разных учеников одного курса разные дни занятий – напишите мне, добавлю дату старта для каждого ученика.

## Безопасность
- Ключ **anon** публичный, его можно хранить на GitHub: без входа учителя он открывает только функции ученика.
- Код ученика – как пароль. Если код попал к чужим, в кабинете нажмите **Выдать новый код**.
- Ключи к практике лежат в отдельном файле и подключаются только в кабинете учителя.
