# Платформа «Учу по ФРП · репетиторство» – как опубликовать и настроить

| Файл / папка | Что это |
|---|---|
| `index.html` | приложение ученика: регистрация по ссылке, уроки в папках, тесты, письмо, доска, статистика |
| `teacher.html` | кабинет учителя: ученики 5–11 классов, планы и даты, проверка работ, своя база, нейросеть |
| `dev.html` | кабинет разработчика: ключи нейросети, оформление сайта, учителя и доступ к встроенным базам |
| `courses/` | встроенная база: ОГЭ (29 уроков), ЕГЭ (27 уроков по заданиям), школьная программа 5–11 по ФРП, входные тесты |
| `supabase/schema.sql` | база данных и права доступа |
| `supabase/functions/ai/index.ts` | серверная функция нейросети (ключи хранятся только на сервере) |
| `bot/` | Telegram-бот с напоминаниями (по желанию) |

Без Supabase сайт работает в демо-режиме: всё хранится только на устройстве.

---

## Шаг 1. База Supabase

1. supabase.com → **New project** (имя `repetitor`, регион Frankfurt).
2. **SQL Editor** → **New query** → вставьте весь `supabase/schema.sql` → **Run** → «Success».
   Файл можно запускать повторно после каждого обновления – данные не удаляются.
3. **Authentication** → **Users** → **Add user** → ваша почта и пароль, галочка **Auto Confirm User**.
4. **Authentication** → **Sign In / Providers**: регистрацию **не выключайте** (репетиторы регистрируются сами), а в разделе **Email** включите **Confirm email**.
5. **Project Settings** → **API** → скопируйте **Project URL** и ключ **Publishable** (или **anon** во вкладке Legacy) в `config.js`. Ключ `service_role` никуда не вставлять.

**Кто разработчик.** Как в «Учу по ФРП»: сначала вход в свой кабинет (почта и пароль), потом код разработчика.
1. Один раз задайте код: Supabase → SQL Editor → `select public.dev_set_code('ваш-код');` → Run. В коде сайта код не хранится, только его хэш в базе.
2. Откройте `dev.html` → войдите почтой и паролем → введите код. После этого кабинет навсегда получает права разработчика.
3. **Вход по коду без регистрации** (для любого человека, которому вы дали код): Supabase → **Authentication** → **Sign In / Providers** → включите **Allow anonymous sign-ins**. Тогда в `dev.html` достаточно имени и кода. Такой вход живёт в одном браузере – в кабинете разработчика можно сразу добавить почту и пароль. Сменить код – в кабинете разработчика; забрать права – в таблице учителей.

## Шаг 2. Нейросеть (проверка сочинений, задания, анализ)

1. Supabase → **Edge Functions** → **Deploy a new function** → **Via Editor**. Имя функции строго: `ai`.
2. Вставьте весь текст `supabase/functions/ai/index.ts` → **Deploy**. Затем в настройках функции выключите **Verify JWT** (Enforce JWT verification): функция сама проверяет, кто её вызывает, а с новыми ключами Supabase без этого ученик не сможет прислать фото работы.
3. Откройте `…/dev.html` → войдите → в разделе **Нейросеть** выберите сервис и вставьте ключ:
   - **DeepSeek** – platform.deepseek.com → API keys (дёшево, хорошо пишет по-русски);
   - **AITUNNEL** – aitunnel.ru, если нужна оплата российской картой;
   - **OpenRouter** или **OpenAI** – тоже подходят.
4. Нажмите **Сохранить** → **Проверить связь**. Должно появиться «Нейросеть отвечает».

Ключ хранится в закрытой таблице, его не видят ни сайт, ни учителя, ни ученики.

## Шаг 3. Публикация на GitHub

Репозиторий `lubagame18-dev/repetitor` → загрузите файлы → **Settings** → **Pages** → Branch `main`, папка `/ (root)` → Save. Сайт откроется по адресу `https://lubagame18-dev.github.io/repetitor/`.

**Живая связь** (курсоры на доске, «кто онлайн и где», мгновенные обновления у ученика после вашей проверки, кнопки «Показать ученику» и «Позвать на доску») работает через Supabase Realtime. Если ученик не появляется онлайн: **Realtime** → **Settings** → включите **Allow public access**.

Смена урока и материала сразу видна ученику – обновлять страницу не нужно. Если урок взят из другого класса или предмета, приложение ученика само переключится на нужный предмет, а значок «онлайн» не пропадёт: он показывается по человеку, под любым его предметом. Кнопка «Показать ученику» открывает урок сразу, даже если он только что добавлен; если ученик был не в сети – урок откроется сам, как только он зайдёт.

**Оформление.** Ученик (и вы) выбирает тему в разделе «Оформление». В одной гамме меняются фон, стекло, папки и кнопки. Тем 16, четыре из них – на ваших фонах. Можно поставить своё фото: цвета папок подберутся по нему. Помощник – котик, утёнок, овечка, ёжик или своя картинка.

## Шаг 4. Первый ученик

1. `teacher.html` → **Добавить ученика** → класс → **Создать ссылку-приглашение** → **Копировать** → отправить ученику.
2. Ученик по ссылке:
   - заполняет анкету: имя, класс, цели (ОГЭ, ЕГЭ, ВПР, контрольные и домашние, олимпиада), контакт;
   - выбирает фон по настроению;
   - придумывает пароль;
   - проходит входной тест своего класса.

   Ссылка одноразовая. Дальше ученик входит логином и паролем.
3. План строится сам:
   - 9 класс + ОГЭ – курс ОГЭ;
   - 10–11 класс + ЕГЭ – курс ЕГЭ;
   - остальные цели – школьная программа своего класса по ФРП.

   Это сработает, если база открыта учителю. Курс можно поменять в карточке ученика.
4. В карточке ученика:
   - **План**: курс и дата первого урока. Дальше уроки идут раз в неделю. Дату любого урока можно поменять прямо в таблице; кнопка «Каникулы» сдвигает все будущие уроки на неделю.
   - **Работа в паре**: выберите напарника. У двоих одна доска на каждом уроке, результаты у каждого свои.
   - **Анализ и план**: нейросеть разбирает тесты, мини-практику, ДЗ, сочинения и время занятий и предлагает уроки повторения. Кнопка **«Добавить урок в план ученика»** добавляет такой урок.
   - **Таблица уроков**: дата, доступ (можно открыть раньше), время в папке, процент выполнения, тест, ДЗ-тест, письмо, ДЗ, доска.
   - **Проверка письма**: текст или фото рукописной работы. Кнопка **«Проверить по критериям»** – черновая оценка нейросети. **«Подставить в оценку»** – баллы переносятся в форму, вы правите и сохраняете. Ученик видит только вашу оценку.

## Шаг 5. Своя база учителя

**Материалы и база** → курс → папка урока → вкладка **«Свои материалы»**:
- ссылка (Учу по ФРП, Google Диск, видео), файл с компьютера (лист, картинка, PDF), текст или задание;
- **Задания от нейросети**: тема → мини-практика и тест → проверить → «Сохранить в папку». Мини-практика появится у учеников в папке, вопросы – в тесте урока.

Внизу списка уроков – **«Свой урок»**: новая папка в курсе с вашей теорией и ДЗ.

Во вкладке **«Лист и ДЗ»** урок скачивается как документ Word: «Тема – рабочий лист» и отдельно «Тема – ключи». Ученик тоже может скачать свою папку кнопкой «Скачать».

## Шаг 6. Встроенные базы и другие учителя

В `dev.html` → **Учителя и встроенные базы** отметьте галочками, какие базы открыты каждому учителю: ОГЭ, ЕГЭ, школьная программа. Учитель без базы видит только названия уроков с замком, но может добавлять свои уроки и материалы.

Там же – **Оформление сайта**: название на экране входа, подпись и фон по умолчанию для новых учеников.

## Как устроен урок (методика)

1. Блок теории.
2. Объяснение на примерах (схемы по обозначениям учебника).
3. **Мини-практика** сразу после блока: ответ проверяется мгновенно, результат идёт в статистику.
4. Следующий блок → снова мини-практика.
5. **Практика** в формате ОГЭ/ЕГЭ и реальные задания из открытого банка ФИПИ.
6. Тест по уроку.
7. Дома: ДЗ, письменная работа, ДЗ-тест.

Вкладки папки ученика: Теория · Практика · Доска · Письмо · Материалы · Домашка · Тест.

## Установка на телефон

- **iPhone**: Safari → «Поделиться» → «На экран Домой».
- **Android**: Chrome → ⋮ → «Добавить на главный экран».

## Как обновлять

1. Загрузите новые файлы на GitHub.
2. Выполните заново `schema.sql` – он безопасен, данные не удаляются. В этом обновлении добавлены таблицы тестов по темам и функции для них, поэтому шаг нужен. Если настроено автообновление базы через GitHub Actions (`.github/workflows/supabase.yml`), база обновится сама при загрузке файлов из `supabase/`.
3. Если менялась функция `ai` – вставьте новый текст и снова **Deploy**.

У учеников обновится само (номер версии в `sw.js` и `?v=` уже увеличен – сейчас `v62`).

## Безопасность

- Ключ **anon** публичный: без входа он открывает только функции ученика по его личному ключу.
- Каждый учитель видит только своих учеников и свои материалы.
- Ключи нейросети – только на сервере.
- Ключи к практике загружаются только в кабинете учителя.
- Фото работ учеников лежат в хранилище `works` по ссылкам со случайными именами. Своё фото для фона хранится только на устройстве.

## Регистрация

Под каждой формой входа есть «Зарегистрироваться»:
- **Учитель** – почта и пароль, подтверждение по письму.
- **Ученик** – по коду учителя. Код и многоразовая ссылка вида `…/repetitor/?t=КОД` – в кабинете учителя, в разделе «Добавить ученика». Одноразовые ссылки-приглашения тоже работают.

## Доступ без подписки

**Сейчас всё открыто бесплатно**: регистрация, добавление учеников, встроенная база (ОГЭ, ЕГЭ, ФРП 5–11), нейросеть (анализ, план, проверка сочинений, задания), доска, видеозвонок, самообучение и тесты по темам. Никакие разделы не блокируются тарифом.

В кабинете учителя раздел называется «Доступ» и объясняет, что включено. Разработчик в `dev.html` → «Тарифы и оплата» может снять галочку «Всё открыто без подписки» — тогда вернутся тарифы и оплата (для истории: базовый 100 ₽, с материалами 300 ₽, полный 500 ₽ в месяц).

**Встроенная база** объединена с «Учу по ФРП»: русский язык (тетради с заданиями и ключами, 5–11), литература 5–11, математика и английский 5–11, история и биология 5–11 (с разработками уроков: проблемный вопрос, план, понятия, даты, вопросы с ответами, мини-практика), география 5–11, физика 7–11, химия 8–11, обществознание 8–11, информатика 7–11, плюс ОГЭ и ЕГЭ по русскому. Учебники и рабочие тетради издательств в базу не переносятся.

В `dev.html` → «Встроенная база по предметам и классам» можно добавлять файлы, ссылки, тексты и уроки в любой предмет и класс – ко всему курсу или к конкретному уроку.

**Встроенная база хранится в Supabase**, а не на GitHub: в `dev.html` → «Встроенная база» загрузите файл `base.json` (его присылает нейросеть). На сайте остаётся только каталог с названиями уроков.

**Оплата через ЮKassa** (подключается на самозанятого или ИП):
1. Supabase → Edge Functions → новая функция `pay` → текст из `supabase/functions/pay/index.ts` → Deploy → выключите **Verify JWT**.
2. В ЮKassa: shopId и секретный ключ → вставить в `dev.html` → «Тарифы и оплата».
3. В ЮKassa → Интеграция → HTTP-уведомления: адрес `https://ВАШ-ПРОЕКТ.supabase.co/functions/v1/pay`, событие `payment.succeeded`.
4. Чеки: для самозанятых ЮKassa может сама передавать чеки в «Мой налог» – включите это в настройках магазина.

## Урок онлайн: звонок, доска и задания сразу

- **Учитель**: карточка ученика → «📞 Начать занятие» (или «▶ Урок» в строке нужного урока). Сразу открывается звонок по личной ссылке ученика, а в кабинете – общая доска и живая тетрадь ученика с ключами, теория и материалы урока. Урок можно сменить вверху.
- **Ученик** получает приглашение и выбирает, что открыть на этом устройстве: «Доска и задания», «Звонок» или «И то и другое». Можно звонок на телефоне, а доску на компьютере. Выбор можно запомнить для устройства. Если ученик зашёл позже, кнопка «Подключиться к уроку» ждёт его на главной и в меню.
- Ученик может сам нажать «▶ Начать урок» в папке – учителю приходит «Подключиться».
- **Другой урок вместо запланированного**: выберите его вверху – он встанет на сегодняшнюю дату, а урок по плану и следующие папки сдвинутся на следующие занятия. «Вернуть план» отменяет перенос.

## Уроки из любого класса и предмета

- Карточка ученика → «Урок из другого класса или предмета»: предмет → класс → урок → дата. Урок копируется в план только этого ученика (и напарника) с заданиями и ключами; галочка «вместо урока на эту дату» сдвигает следующие папки. Убрать – «убрать» в таблице уроков.
- «Материалы и база» → любой класс → папка урока → «В план ученика» – на ближайший урок.
- Во время урока онлайн – «+ Из другого класса» → «Провести сейчас»: урок сразу открывается у ученика, план сдвигается на занятие вперёд.

## Видеозвонок на платформе и перенос ученика

- **Видеозвонок встроен в урок**: небольшое окно сбоку внизу (учитель и ученик), доска и материалы остаются открытыми. Кнопки: микрофон, камера, размер окна, выйти. Как только соединение установилось, учитель и ученик сразу оказываются на доске урока. Ссылка на Телемост остаётся запасной кнопкой «Звонок по ссылке».
- Звонок идёт напрямую между устройствами. В редких сетях (строгий школьный или офисный интернет) прямое соединение не проходит – тогда нужен TURN-сервер: добавьте в `config.js` строку `TURN: [{urls: "turn:адрес:3478", username: "…", credential: "…"}]`.
- Ученик выбирает на устройстве: «Доска и видеозвонок», «Только доска и задания» или «Только видеозвонок» (например, звонок на телефоне, доска на компьютере).
- **Перенос ученика**: у учителя на уроке те же вкладки, что у ученика (Теория, Практика, Письмо, Материалы, Домашка, Тест). Откройте нужный урок и вкладку → «➜ Перенести ученика сюда».
- **Тесты вживую**: ученик проходит тест прямо на уроке, учитель видит вопрос и каждый ответ.
- **Несколько уроков за занятие**: урок, с которым работали больше 3 минут, отмечается «пройден на уроке» в таблице ученика и открывается ему.
- **Класс и подготовка**: цели зависят от класса (ОГЭ – 8–9, ЕГЭ – 10–11). В приглашении можно сразу выбрать подготовку – тогда ученик её не меняет, план настроен.

## Доска: материалы, листы и текст

- **Один лист на двоих**: на уроке учитель видит на доске тот же лист, что и ученик, поэтому подчёркивания и пометки ложатся ровно туда, где их делают. Свои ключи, ответы и подсказки учитель по-прежнему видит в правой панели комнаты. Собственные пометки учителя на доске (штрихи, надписи, картинки) сохраняются и синхронизируются как обычно.
- **Выгрузка материала**: 📎 (или фото с камеры, перетаскивание файла, вставка из буфера) → «Куда выгрузить материал?»:
  - «На этот лист» – картинки и страницы PDF лягут на текущий лист, друг под другом, без наложений;
  - «Отдельными листами» – документ Word, презентация, PDF или картинка станут отдельными листами доски.
  Добавленные листы и материалы сохраняются в базе: не пропадают после смены вкладки, перезахода и у второй стороны. Слишком большие файлы сохраняются в урезанном виде – об этом появится сообщение.
- **Перемещение**: инструмент ✥ – тащите картинку или надпись в нужное место; положение сохраняется и сразу видно второй стороне.
- **Текст**: инструмент T → ткните в любое место листа → появится окошко, куда можно печатать. Размер окошка меняется за правый нижний угол; «Готово» или Enter – сохранить, Shift+Enter – новая строка, Esc – отмена. Готовую надпись можно передвинуть (✥) или стереть (⌫).
- **Штрихи не расходятся с текстом**: подчёркивания и пометки привязаны к словам листа, поэтому даже если на телефоне ученика и на компьютере учителя текст переносится чуть по-разному, штрих остаётся на том же предложении.
- **Ещё на доске**: снимок листа 📸 (картинка со всеми пометками), встраивание сайтов (Wordwall, YouTube, Google Презентации, Canva), частичный ластик, сглаженные штрихи, листание ‹ › / стрелками / свайпом.

## Тесты по темам и карта ошибок

- **Пройдено ≠ выполнено.** В карточке ученика → таблица уроков: колонка «Выполнено» показывает, сколько заданий/тестов пройдено, а рядом отдельная колонка «Пройдено» – учитель вручную отмечает темы, которые прошли очно или на другой платформе (кнопка «Отметить», дата сохраняется; можно снять).
- **Тест по нескольким темам.** В карточке ученика, блок «Тест по темам»: отметьте нужные темы, выберите число вопросов на тему и нажмите «Собрать тест». Вопросы берутся из тестов уроков, недостающие – составляет нейросеть (с объяснением). Проверьте предпросмотр (лишний вопрос можно убрать), сохраните – появится ссылка вида `index.html?quiz=КОД`.
- **Отправка ученику**: скопируйте ссылку или нажмите «Открыть у ученика» – тест откроется у него сразу. После сохранения тест сразу появляется у ученика в разделе «Тесты» (даже если ссылку не отправляли), а ссылка `index.html?quiz=КОД` открывается и в браузере учителя – без перехода в кабинет учителя.
- **Как проходит ученик**: вопрос → сразу объяснение; если ответ неверный, тот же вопрос даётся ещё раз (2 попытки). Если и повторно неверно – тема помечается «надо доработать». В конце – результат и список тем для повторения.
- **Результат – по первой попытке**: в зачёт идёт только верный ответ с первой попытки. Если ученик ошибся и исправился на второй попытке, процент будет немного ниже (на экране итогов так и написано: «Правильно с первой попытки: X из N»), а тема видна в карте как требующая закрепления.
- **Если темы не выбраны** – кнопка «Собрать тест» автоматически берёт темы, отмеченные «Пройдено» (до 8), и собирает тест по ним. Можно выбрать темы и вручную.
- **Карта тем.** По результатам тестов строится визуальная карта: темы с ошибками сверху, красным – «надо доработать»; видно, сколько верных с первой попытки. У учителя – в карточке ученика, у ученика – в разделе «Тесты» (там же список тестов от учителя и история).

## Самообучение: подготовка к ОГЭ без репетитора

Раздел «Самообучение» у ученика теперь – полноценный тренажёрный зал по экзаменационным темам.

- **Ударения ОГЭ** – 12 блоков по 15 слов (180 слов орфоэпического минимума). Блок засчитывается, когда все 15 слов отвечены верно. Если ученик ошибся – показывается правильное ударение и слово возвращается в конец очереди ещё два раза; при повторной ошибке – снова дважды, пока не запомнит. Пока идёт блок, видно «освоено X из 15 · в очереди N · ошибок M». Прогресс сохраняется на сервере: можно продолжить с другого устройства, блоки отмечаются ✓.
- **Карточки-запоминалки** – паронимы (29 пар), средства выразительности (20 карточек), а на исторических курсах – даты, термины и личности (46 карточек). Карточка → «Показать ответ» → «Знаю» или «Ещё учить»; при «Ещё учить» карточка возвращается ещё два раза.
- **Мои ошибки** – слова ударений и карточки, в которых ученик ошибался, собираются в отдельный тренажёр. Пока не ответит верно – ошибка не уходит. Это персональный список для повторения.
- **Что подтянуть** – вверху раздела: слабые задания ОГЭ (по результатам отработок и пробных вариантов) и следующий незаконченный блок/колода. Кнопка сразу открывает нужный тренажёр.
- Прогресс самообучения хранится в базе (таблица `works`), поэтому он не теряется при смене устройства; без связи – копится локально и отправится позже.

### Что видит учитель в карточке ученика

В карточке ученика, в блоке **«Всё, что делает ученик»**:
- **Самообучение: прогресс** – те же 12 блоков ударений (X/15, ошибки, ✓), колоды карточек (X/N), список «Мои ошибки» с правильными вариантами;
- **База и материалы ученика** – курс, предмет и класс, сколько уроков открыто из скольких, сколько материалов выдано (с названиями), последняя активность;
- **Доска ученика: пометки и подчёркивания** – по каждому листу видно, сколько штрихов, надписей и вложений сделал ученик, когда была последняя пометка, и кнопка «Открыть доску»: учитель видит ту же доску с пометками (подчёркивания, надписи, вложения), что и ученик. Кнопка «Обновить» перечитывает доску.

### Динамика успеваемости

В карточке ученика у учителя и в разделе «Статистика» у ученика есть **график динамики**: волнистая линия по темам и занятиям от начала до текущего момента. Каждая точка – результат пройденного занятия, теста, ДЗ или теста по темам; линия поднимается и опускается в зависимости от результатов. Рядом – «сейчас N%», изменение за период и подписи тем. График строится по всем предметам ученика и обновляется после каждого занятия.

### База самообучения и свои задания

В карточке ученика есть блок **«База самообучения: задания и конструктор»**:
- **Показать базу** – учитель видит все встроенные задания: 12 блоков ударений (180 слов) и колоды карточек (паронимы, средства выразительности, история) с полным содержимым;
- **Создать набор** – свои ударения (по одному слову в строке, ударная гласная заглавной: `звонИть`) или карточки (`вопрос | ответ`), на весь курс или только этому ученику. Набор сразу появляется у ученика в «Самообучении» с пометкой «от учителя»; прогресс ученика по своим заданиям учитель видит в карточке (X/N, ошибки), набор можно изменить или удалить.

## Проверки (для разработчика)

В папке `_test/` – автоматические проверки без npm и сети: доска (якоря, вложения, перемещение, текст, единый фон), комната учителя, «показ урока», тесты по темам и ручное «пройдено» – на моках Supabase. Запуск из папки проекта:

```
node _test/run.mjs       # всё: стенд доски + e2e учитель/ученик
node _test/board.mjs     # только стенд доски
node _test/e2e.mjs       # только живые сценарии на mock Supabase
```

Нужен Chrome/Edge и Node 22+. Подробности – `_test/README.md`.
